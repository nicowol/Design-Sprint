# College Quest Prototype

College Quest is an interactive roadmap that introduces students to the main stages of planning for and applying to college.

## Installation

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Start a local web server:

   ```bash
   python3 -m http.server 8000
   ```

4. Visit [http://localhost:8000](http://localhost:8000) in a web browser.

No additional packages or installation steps are required.

## Using the prototype

- Select a world from the home page.
- Choose the highlighted roadmap node to open an activity.
- Complete activities to unlock the next step.
- Use the numbered buttons at the bottom to preview other worlds.
- Select **World map** to return to the home page.

Progress is temporary and resets when the page is refreshed.
